# Pistas y reintentos

Reglas actualizadas el 12 de septiembre de 2026:

- Las instalaciones nuevas reciben una pista de bienvenida. Después se obtienen pistas con anuncios recompensados, respetando la disponibilidad y las reglas de anuncios existentes. Los saldos de bienvenida guardados anteriormente se conservan.
- Tras fracasar, cada reto permite dos reinicios gratuitos por día UTC. El cupo se guarda localmente y se renueva a las 00:00 UTC; cerrar la aplicación o volver desde el inicio no lo reinicia.
- Agotado el cupo, cada reinicio requiere una recompensa confirmada. Si no hay anuncio o no se completa, no se concede el reinicio. El jugador puede volver más tarde o esperar la renovación diaria.
- La recompensa de un reinicio no concede pistas. Las recompensas recibidas tarde se conservan para ese reto y no se duplican.
- La compra Sin anuncios conserva las tres pistas diarias y permite reinicios sin publicidad.
- Reiniciar comienza el reto desde cero. No se ha añadido recuperación parcial de una partida.

Estas reglas sustituyen la indicación anterior de reinicios siempre gratuitos en la estrategia de anuncios. La frecuencia de intersticiales no cambia en este ajuste.
